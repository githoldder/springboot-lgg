# springboot-lgg

第五组分布式应用技术课程大作业。

本项目以 Spring Boot 为后端基础，融合若依后台管理框架与绿果果生鲜业务模块，当前演示口径统一为“绿果果生鲜运营系统”。前端管理端使用 RuoYi-Vue3 技术栈，后端使用 RuoYi-Vue 单体分层架构承载业务模块，小程序端保留为用户下单入口。

## 本地运行入口

- 后端服务：`ruoyi-vue-lgg-backend`，默认端口 `8081`
- 管理后台：`ruoyi-vue-lgg-frontend`，默认端口 `8082`
- 微信小程序：`mp-weixin`
- 一键启动：`./start-all-services.sh`
