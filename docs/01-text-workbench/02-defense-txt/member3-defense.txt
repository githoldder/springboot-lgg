问题 2：项目为什么保留 Docker Compose 分支但现场优先使用 PM2？
回答：
Docker Compose 适合体现工程化部署能力，但现场演示受机器环境影响较大。PM2 更适合本地快速启动和状态管理，因此主分支优先保证 PM2 演示稳定，Docker Compose 作为加分扩展分支。

问题 3：MinIO 在项目中的作用是什么？
回答：
MinIO 是本地对象存储服务，可替代真实云 OSS，用于水果图片或附件上传演示，便于本地部署和截图展示。

问题 4：Playwright 和 Apifox CLI 的区别是什么？
回答：
Apifox CLI 或 Newman 主要用于接口层测试，验证后端 API 是否可用；Playwright 用于浏览器端到端测试，验证用户从登录到业务页面操作的完整流程。

问题 5：项目后续还可以如何改进？
回答：
后续可以完善小程序页面体验，增加真实图片上传，补充更多业务数据，并提升报告中的测试覆盖和截图完整度。
