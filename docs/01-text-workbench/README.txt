绿果果课程大作业纯文本工作区

本目录是以后修改报告正文和答辩记录的唯一主要工作区。

目录说明：

00-extracted-sources
  从课程指导书、提交说明、模板、第八组参考报告等原始材料中抽取出的纯文本。
  这些文件用于参考，不建议直接作为第五组最终正文。

01-report-txt
  第五组项目设计报告正文。以后报告修改优先改这里。

02-defense-txt
  第五组成员个人答辩记录。成员信息补齐后在这里维护。

03-screenshot-placeholders
  报告需要截图的占位符清单和粘贴说明。

scripts
  文本抽取脚本和辅助工具。

注意：
Word 由人工打开模板后粘贴，不再用 LibreOffice 自动排版。
