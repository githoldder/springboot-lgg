Figure 目录说明

本目录用于管理报告里的所有截图、PDF 页图和截图占位符。

screenshot-checklist.txt
  报告截图清单。每个截图都有固定编号，例如 S01-PM2服务状态。

screenshots
  手动截图后放这里，建议命名为 S01-PM2服务状态.png。

pdf-pages
  如果需要把参考 PDF 页面渲染为图片或留存页图，放这里。

使用规则：
1. txt 正文中只写 [截图占位符: Sxx-名称]。
2. 截图实际文件放 screenshots。
3. PDF 页图放 pdf-pages。
4. Word 最终排版时人工插图并添加题注。
