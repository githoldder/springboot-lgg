绿果果课程大作业 02-process 处理区

本目录是以后修改报告正文、答辩记录、截图清单、PDF 页文本和辅助脚本的主要工作区。

目录说明：

Figure
  放截图清单、实际截图、PDF 页面图。报告里的截图占位符也在这里维护。

prompt
  放可复用提示词模板。模板必须与具体课程内容解耦，便于迁移到其他课程设计。

data
  放从原始输入源抽取出的 txt 文本和其他中间数据。

script
  放文本抽取、目录检查、报告辅助处理脚本。

document
  放最终要粘贴进 Word 的纯文本正文、答辩记录和粘贴脚本。

data/extracted-sources
  从课程指导书、提交说明、模板、第八组参考报告等原始材料中抽取出的纯文本。

document/report-txt
  第五组项目设计报告正文。以后报告修改优先改这里。

document/defense-txt
  第五组成员个人答辩记录。成员信息补齐后在这里维护。

注意：
Word 由人工打开模板后粘贴，不再用 LibreOffice 自动排版。
