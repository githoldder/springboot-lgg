D. 格式对齐
========================

[ ] 页边距: 上 2.5cm / 下 2.5cm / 左 3cm / 右 2.5cm (或按学校模板)
[ ] 正文字体: 宋体小四 (12pt)，行距 1.5 倍
[ ] 标题字体: 一级黑体三号 / 二级黑体四号 / 三级黑体小四
[ ] 代码块: Consolas 或 Courier New 五号 (9pt)，灰色底纹
[ ] 图题注: 宋体五号 (10pt)，居中，编号连续
[ ] 表题注: 宋体五号，居左
[ ] 页码: 目录页用罗马数字，正文从第 1 页阿拉伯数字起始
[ ] 页眉: 奇数页 "绿果果生鲜分布式运营系统"，偶数页 "第 X 章 XXXX"
