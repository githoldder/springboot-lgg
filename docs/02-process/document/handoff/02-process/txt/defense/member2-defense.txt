问题 2：Gateway 在系统中的作用是什么？
回答：
Gateway 是系统的统一入口，前端请求可以先进入网关，再由网关根据路由规则转发到后台管理服务、业务服务、支付服务或通知服务。

问题 3：Redis 在项目中解决了什么问题？
回答：
Redis 可用于验证码、登录态、缓存和热点数据处理，能够减少数据库访问压力，提高系统响应速度。

问题 4：RabbitMQ 为什么适合用于支付成功通知？
回答：
支付成功后不需要同步完成所有后续处理，可以通过 RabbitMQ 发送支付成功事件，由通知服务异步消费并推送包装提醒，从而降低服务耦合。

问题 5：系统目前已实现哪些生产级质量保障措施？
回答：
系统已在多个层面落实质量保障：基于 JWT + Spring Security 的网关鉴权，支持角色粒度权限控制；采用 Publisher Confirm + 手动 ACK 确保 RabbitMQ 消息不丢失；通过 Actuator 暴露各服务 /actuator/health 健康端点，Nacos 实时反映实例健康状态；MyBatis-Plus 物理分页 + Redis allkeys-lru 缓存策略保障查询性能；订单状态机采用单向递增设计，避免非法状态回溯。后续计划引入 Sentinel 限流和 SkyWalking 链路追踪，进一步增强系统的生产可用性。
