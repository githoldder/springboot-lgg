问题 2：本项目为什么采用 Spring Boot 与 Spring Cloud Alibaba？
回答：
Spring Boot 适合快速构建独立后端服务，Spring Cloud Alibaba 提供 Nacos、Gateway、OpenFeign 等组件，能够体现服务注册、统一入口和服务间调用等分布式应用技术。

问题 3：Nacos 在系统中的作用是什么？
回答：
Nacos 用于服务注册与发现，各个后端服务启动后会注册到 Nacos，Gateway 可以通过服务名发现并转发请求，便于服务治理和扩展。

问题 4：PM2 在本地演示中的作用是什么？
回答：
PM2 用于管理本地长运行进程，可以统一查看服务状态、重启服务和查看日志，避免手动启动产生僵尸进程，提高现场演示稳定性。
