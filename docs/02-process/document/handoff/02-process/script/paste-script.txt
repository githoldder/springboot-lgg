========================
六、txt 正文中占位符说明 (v3.0 更新)
========================

在 00-report-master.txt 各章节中，占位符的格式统一为一行独立标记，便于
Ctrl+F 快速定位:

  [截图占位符: logo-springboot - Spring Boot 技术标识]
  [工程图占位符: U01-系统架构图]
  [截图占位符: S10-核心运营多维统计图表]

Word 粘贴时操作步骤:
  1. 在 Word 中按 Ctrl+F 搜索 "占位符" 定位
  2. 删除该占位符行
  3. 在删除位置粘贴对应图片
  4. 图片下方添加题注 (参考 → 插入题注, 编号按章递增)

部分位置存在多个占位符聚集 (如 Ch3 架构图 + S01/S02/S03 四连占位符、
Ch4 4.4 节 U03/S05/S06/S09 四连占位符)，粘贴时按出现顺序逐一处理。
