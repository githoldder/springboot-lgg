## 五、更新报告的操作方法

### 方案A：使用 Word 版报告
1. 打开 `02-process/doc/项目设计报告-模版.docx`
2. 将 `02-process/Figure/screenshots/` 中的 PNG 拖入对应位置
3. ⚠️ **注意**：S08 已废弃，使用 S13 替代；S09 用途变更；新增 S16
4. 参考 `02-process/txt/chapters/` 中的文本更新对应章节内容
5. 导出 PDF 至 `03-report/pdf/`

### 方案B：继续使用 LaTeX
1. 新截图覆盖到 `latex/分布式/figures/` 目录
2. 小程序截图（S07/S14/S15）需同时更新 `figures-pdf/` 中的 PDF
3. 执行编译命令（见第四节）
