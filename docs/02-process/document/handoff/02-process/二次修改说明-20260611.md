### 5. 替换图片的操作方法

**方案 A: 替换 Word 报告中的图片**

1. 打开 `02-process/doc/02.项目设计报告-模版.docx` 或最终报告
2. 按 `paste-script.txt` 指引，将 `02-process/Figure/screenshots/` 中的 PNG 图片拖入对应位置
3. 图片命名规则：`S{NN}-{描述}.png`，其中 NN 为两位数序号

**方案 B: 更新 LaTeX 并重新编译**

1. 将新 PNG 覆盖到 `latex/分布式/figures/` 目录
2. 如果 LaTeX 引用的是 `figures-pdf/` 中的 PDF（如 S07/S14/S15），需要将新 PNG 转换为 PDF
3. 执行：`xelatex thuthesis-example.tex && bibtex thuthesis-example && xelatex thuthesis-example.tex && xelatex thuthesis-example.tex`
