答辩记录  问题 1：查询出多个结果应该如何存储  
答：从数据库或其他数据源查询出多个结果时， 通常会将这些结果存储在集
合类型中，比如  List、Set 等。最常见的是使用  List，因为它有序且允许重复
元素，适合大多数业务场景。比如查询用户列表、文章列表等，都会
用 List<User> 、List<Article>  这样的形式来存储。如果涉及分页，还可以封装
成自定义的分页对象，方便前后端数据交互和展示。  
问题 2：使用多个条件如何查询  
答：使用 mybatis通常会在  Mapper 的 XML  文件中编写动态  SQL，通
过 <where>  和 <if> 标签灵活拼接查询条件。这样可以根据传入参数的不
同，动态生成对应的  SQL 语句，实现多条件组合查询。例如，可以根据用户
名、状态、年龄等多个字段进行筛选，只有当参数不为空时才拼接对应的条
件，从而提高查询的灵活性和效率。
