# Sprint 07 PRD: 成交转化、复购基础与售后口碑 MVP

Last Updated: 2026-07-17

## 大目标

把当前“能下单”的 MVP 推进到“能转化、能复购、能处理售后、能沉淀口碑”的业务系统。Sprint07 聚焦最短路径：广告轮播图、商品详情页、优惠券 MVP、会员 MVP、用户评价、商家回复、售后工单。

---

## 当前真实状态

| 模块 | 当前状态 | 风险 |
|---|---|---|
| 首页转化 | 已有首页和分类商品浏览，但活动位和推荐位不足 | 用户难以快速看到爆品/特价 |
| 商品详情 | 已有 `mp-weixin/pages/details`，但详情信息和评价摘要不足 | 用户购买决策信息不足 |
| 优惠券/会员 | 当前无完整营销闭环 | 缺少首单/复购激励 |
| 评论 | 当前无订单后评价与商家回复闭环 | 无法沉淀口碑和商品反馈 |
| 售后 | 当前主要依赖人工沟通 | 坏果、漏送、退款无法结构化留痕 |

## Decision Hierarchy

| Epic | Module | Feature | User Story | Task |
|---|---|---|---|---|
| Epic A | 广告轮播 | 首页活动位 | 作为学生用户，我希望一打开首页就看到今日特价和爆品，以便快速决定买什么 | 建 `lgg_banner`；后台 CRUD；小程序首页读取；支持跳转商品详情 |
| Epic A | 商品详情 | 商品详情页 | 作为用户，我希望看到图片、规格、库存、销量、评价，再决定是否加购 | 补接口 VO；详情页展示；规格选择；加购复用购物车接口 |
| Epic A | 优惠券 | 下单抵扣 | 作为用户，我希望下单时能使用优惠券，以提高购买意愿 | 建券表/用户券表；后台发券；用户券列表；订单金额计算接入 |
| Epic A | 会员 | 会员 MVP | 作为复购用户，我希望看到会员身份和权益，以形成复购激励 | 增会员字段/表；我的页展示；订单完成后成长值增加 |
| Epic A | 评论 | 用户评价 | 作为用户，我希望完成订单后评价商品，帮助他人判断品质 | 建评价表；订单完成后评价校验；小程序评价入口；商品详情展示摘要 |
| Epic A | 评论 | 商家回复 | 作为商家，我希望回复差评或解释售后方案，以维护口碑 | 后台评论列表；回复字段；隐藏状态；字典状态 |
| Epic A | 售后 | 售后申请 | 作为用户，我买到坏果或漏送时希望直接提交售后 | 建售后表；订单详情入口；原因/类型；状态流转 |
| Epic A | 售后 | 后台处理 | 作为运营者，我希望集中处理退款/补发/拒绝，避免遗漏 | 后台售后列表；详情；处理备注；状态变更；操作日志 |

## 范围边界

- 优惠券只做满减/立减 MVP，不做叠加券、平台券、品类券组合。
- 会员只做等级、成长值、权益展示，不做付费会员和积分商城。
- 售后只做工单，不做实时客服 IM。
- 评论只做订单后评价和商家回复，不做社区内容流。
- 后端新增业务优先放在 `ruoyi-business`，不新增微服务。

## 验收标准

- 用户能从轮播图进入商品详情并完成加购/下单。
- 用户可领取或获得优惠券，并在下单页看到可用、已用、过期状态。
- 已完成订单可评价，未完成或非本人订单不可评价。
- 商家可回复评价，商品详情展示评价摘要。
- 用户可基于订单提交售后，后台可处理并留痕。
