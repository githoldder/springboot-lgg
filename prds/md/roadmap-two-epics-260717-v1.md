# Second Iteration Roadmap: 业务流水线 + AI 增强业务中台

Last Updated: 2026-07-17

## Vision

把常工鲜生从“可演示的校园水果下单 MVP”推进为“可运营、可复购、可观察、可逐步智能化的一人公司业务系统”。本阶段分成两个 Epic：先补齐水果生鲜公司的完整业务流水线，再在真实业务数据和 API 之上接入推荐算法、LangChain/LangGraph 与多 Agent 运营助手。

---

## Epic A: 水果生鲜公司完整业务流水线

目标：围绕获客展示、商品转化、订单履约、售后处理、评价口碑、复购营销、角色协作和运营监控，补齐真实经营闭环。

范围边界：
- 后端优先复用 `ruoyi-business`，不新增业务微服务。
- 管理端页面统一放入 `ruoyi-vue-lgg-frontend/src/views/business/*`。
- 小程序优先复用 `index`、`details`、`order`、`historyOrder`、`my`。
- RuoYi 的角色、菜单、字典、日志、监控、定时任务优先复用。
- 客服售后降级为工单，不做实时 IM。
- 优惠券只做满减/立减和状态管理 MVP。
- 会员只做等级、成长值和权益展示 MVP。

成功指标：
| 指标 | 验收口径 |
|---|---|
| 下单转化 | 用户能从轮播、瀑布流、商品详情进入加购与下单 |
| 售后闭环 | 用户可提交售后，后台可处理并留痕 |
| 口碑闭环 | 用户完成订单后可评价，商家可回复或隐藏 |
| 复购闭环 | 优惠券和会员状态影响用户端展示与下单抵扣 |
| 权限闭环 | 管理员、商家、骑手、用户角色边界清晰 |
| 运营闭环 | 管理端可查看订单、销量、履约、售后、评价、用券等指标 |

---

## Epic B: AI 增强业务中台

目标：在真实业务闭环之上，逐步接入规则推荐、AI 文案/客服、LangChain/LangGraph 工作流，并最终演进为辅助一人公司运营的多 Agent 系统。

范围边界：
- AI 不替代订单、支付、库存、退款等核心事务。
- 早期不训练重模型，不建设复杂 ML 平台。
- AI 客服先生成草稿，必须人工确认。
- 推荐先做规则权重和可解释理由，再做 AI 润色和策略建议。
- LangChain/LangGraph 作为独立编排层调用业务 API，不侵入核心交易链路。

成功指标：
| 指标 | 验收口径 |
|---|---|
| 推荐可解释 | 首页推荐能返回热销、复购、库存、活动等理由 |
| 数据可沉淀 | 曝光、点击、加购、下单、评价等行为可记录 |
| AI 可降级 | AI 调用有统一入口、日志、超时、mock 和失败回退 |
| 人工可控 | 评价润色、客服话术、运营建议均需人工确认 |
| Agent 可观测 | Agent 输入、输出、工具调用、审批记录可追踪 |

## Roadmap

| Sprint | Epic | Theme | Outcome |
|---|---|---|---|
| Sprint07 | Epic A | 成交转化 + 复购基础 + 售后口碑 MVP | 轮播图、商品详情、优惠券、会员、评价、售后进入可用闭环 |
| Sprint08 | Epic A | 多角色履约 + 运营治理 | 管理员、商家、骑手权限划分，骑手任务页，RuoYi 监控复用 |
| Sprint09 | Epic A + Epic B | 首页瀑布流 + 规则推荐 + AI 数据底座 | 规则推荐跑通，用户行为埋点，为 AI 接入准备数据和接口边界 |
| Sprint10 | Epic B | LangChain/LangGraph 业务辅助 | AI 评价润色、FAQ 回复草稿、推荐理由润色、日经营摘要 |
| Sprint11 | Epic B | 多 Agent 运营助手雏形 | 运营 Agent、客服 Agent、推荐策略 Agent 输出建议并走人工审批 |

| Epic A | S07 | 转化 | 首页轮播图、商品详情页 | P0 |
| Epic A | S07 | 复购 | 优惠券 MVP、会员 MVP | P0/P1 |
| Epic A | S07 | 服务 | 售后工单、用户评价、商家回复 | P0 |
| Epic A | S08 | 履约 | 骑手任务、商家权限、角色划分 | P0 |

## Non-Goals

- 不在第二次迭代早期建设完整 IM 客服系统。
- 不在 Sprint07-S09 做复杂机器学习训练。
- 不让 AI 自动退款、自动改价、自动发券或自动修改库存。
- 不新增过多微服务，避免一人公司阶段运维成本失控。
